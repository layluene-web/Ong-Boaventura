# Ong Boaventura

Site institucional da Ong Boaventura, um espaço de acolhimento e apoio para mães.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript (Vanilla)

## Funcionalidades
- Navegação SPA (Single Page Application) com fetch e history API
- Cadastro com validação de campos via RegEx (CPF, telefone, CEP)
- Máscaras de formatação automática nos campos de entrada
- Persistência de dados no localStorage
- Depoimentos gerados dinamicamente via template literals

## Como executar
1. Clone o repositório
2. Abra o projeto com a extensão Live Server no VS Code
3. Acesse pelo navegador
